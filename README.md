# FrameForge

Конвертер фото и видео в GIF-анимацию с десктопным интерфейсом на Python (PyQt6).

Быстро превращает набор изображений или фрагмент видео в зацикленную GIF-анимацию:
обрезка видео маркерами, настройка скорости, качества и размера, предпросмотр результата прямо в приложении.

## Возможности

- **Фото → GIF** (JPG, PNG):
  - порядок кадров = порядок выбранных файлов;
  - лишний кадр удаляется крестиком на миниатюре;
  - настройка скорости (задержка кадра, мс) и качества (размер палитры: Low / Medium / High).
- **Видео → GIF** (MP4, MOV, AVI):
  - выбор фрагмента маркерами на шкале либо точным вводом «Старт»/«Конец»;
  - предпросмотр показывает только выбранный фрагмент;
  - настройка FPS и размера кадра в процентах.
- **Общие параметры**: режим «Дитеринг» (лучше цветовые переходы) или «Быстрая» (скорость), зацикливание анимации.
- **Предпросмотр** анимации и готового GIF.
- **Кастомная рамка окна**: свой заголовок, перетаскивание, изменение размера за края, сворачивание/разворачивание/закрытие.
- **Встроенная справка** (кнопка «?»).

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) — менеджер пакетов и окружений
- ОС: Windows 10/11 или Linux (Ubuntu)

## Установка

### Из готового релиза

Скачайте архив из раздела [Releases](https://github.com/hikara33/GIF-creator/releases):

- **Windows** — `FrameForge-Windows.exe`: запустите файл — приложение откроется без установки.
- **Linux** — `FrameForge-Linux`:

  ```bash
  chmod +x FrameForge-Linux
  ./FrameForge-Linux
  ```

### Из исходников

1. Клонируйте репозиторий и перейдите в него:

   ```bash
   git clone https://github.com/hikara33/GIF-creator
   cd GIF-creator
   ```

2. Установите зависимости:

   ```bash
   uv sync
   ```

   Для разработки (добавляет `pytest`, `ruff`, `pyinstaller`):

   ```bash
   uv sync --dev
   ```

## Запуск

```bash
uv run python -m main
```

или

```bash
uv run python main.py
```

## Тесты и линтинг

```bash
uv run pytest        
uv run ruff check .
```

## Сборка релиза

Локально (нужен `uv sync --dev`):

```bash
uv run pyinstaller gif_creator.spec
```

Результат появится в `dist/`: `FrameForge.exe` (Windows) или `FrameForge` (Linux).

Автоматическая сборка: пуш тега вида `v1.0.0` запускает GitHub Actions, который собирает версии для Windows и Linux и создаёт черновик релиза с артефактами.

## Структура проекта

```
main.py                    # точка входа приложения
gif_creator.spec           # конфигурация PyInstaller
gui/                       # интерфейс (PyQt6)
├── main_window.py         # главное окно
├── video_editor.py        # редактор видео: обрезка фрагмента
├── icons.py               # SVG-иконки интерфейса
├── types.py               # типы: MediaKind, UploadedMedia, пресеты качества
├── worker.py              # фоновая сборка GIF (QThread)
├── resources/             # палитра, QSS-тема, иконка приложения
└── widgets/               # переиспользуемые виджеты
core/                      # движок создания GIF
├── pipeline.py            # конвейер: кадры → палитра → квантизация → сжатие
├── median_cut.py          # построение цветовой палитры
├── floyd_steinberg.py     # дизеринг
├── lzw.py                 # LZW-сжатие
├── gif_encoder.py         # кодирование кадров в формат GIF
└── motion_blur.py
io_module/                 # ввод-вывод
├── image_reader.py        # чтение последовательностей изображений
├── video_reader.py        # извлечение кадров из видео (OpenCV)
└── gif_writer.py          # запись GIF-файла
utils/
└── metrics.py             # метрики качества
tests/                     # unit и integration тесты
```

## Технологии

- **PyQt6** — графический интерфейс
- **numpy** + **numba** — быстрые вычисления (JIT-компиляция)
- **OpenCV** — извлечение кадров из видео
- **Pillow** — работа с изображениями
- **scipy** — научные алгоритмы
- **PyInstaller** — сборка автономных исполняемых файлов
